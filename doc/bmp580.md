# BMP580 pressure sensor

Connect the sensor to 3.3 V, ground, SDA and SCL. Use pull-ups to 3.3 V on SDA and SCL if the breakout does not provide them. Keep CSB high for I²C. The driver probes both 7-bit addresses, `0x46` and `0x47`, and checks register `0x01` for chip ID `0x50` before configuring the sensor.

The supplied `WAVESHARE_LITE` profile uses GPIO 26 and 27 on I²C1 for the GATASPulseLR2021 sensor. Enabling Bmp580 disables the status LED when it shares either I²C pin.

For other wiring, add a `Bmp580` pin map under the selected board profile in the firmware configuration or its `src/pico/gatas_local_config.json` overlay. For example, this overlay uses GPIO 4 and 5 on I²C0. Substitute free GPIOs that belong to the same I²C controller on your board.

```json
{
  "PICO_2RADIO": {
    "Bmp580": { "SDA": 4, "SCL": 5 }
  }
}
```

With that profile active, enable Bmp580 in the Modules page or add `Bmp580` to the configured modules list, then restart. Use one internal pressure sensor at a time.

An absent sensor, unexpected chip ID or failed initialization is reported as a hardware error in Modules. Once running, the driver publishes fresh, factory temperature-compensated pressure in hPa once per second. Failed reads leave the last sample to expire normally.
